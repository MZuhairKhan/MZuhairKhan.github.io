Selected through Aaltoes' competitive **Harbor** programme for a project engagement with **Lifeline Ventures**, a Helsinki seed VC. The work centred on the firm's fund operations and data:

- **Quarterly-review automation** — redesigned the reporting process to run on Lifeline's new AWS data warehouse, cutting manual data entry and improving coverage.
- **Fund-modelling tool** — built fund-level views comparing planned vs actual performance across investments.
- **Data architecture** — mapped fragmented investment data (Atominvest, Greenstep spreadsheets) toward a unified model, and scoped where AI agents (e.g. a Slack assistant over investment documents) add the most value.

The engagement continued into an ongoing Data Engineer role at Lifeline.
